# 🤖 ربات تلگرامی فروش فیلترشکن (VPN Shop Bot)

ربات کامل فروش اشتراک VPN با **Python + aiogram 3** — بدون دیتابیس خارجی؛ همه‌چیز فقط روی خود سرور (SQLite).

## ✨ امکانات

**پنل کاربری 👤**
- 🛒 خرید پلن (روزانه / هفتگی / ماهانه / سه‌ماهه و هر پلن دلخواه — تعریف توسط ادمین)
- 💳 پرداخت کارت‌به‌کارت + ارسال رسید (عکس یا شماره پیگیری)
- 📦 مشاهده اشتراک‌های فعال + باقی‌مانده
- 📋 دریافت کانفیگ (VLESS / VMess / Trojan / Reality — هر متنی که ادمین ثبت کند)
- 🔄 تمدید خودکار (خرید جدید به اشتراک فعال اضافه می‌شود)
- 🆘 تیکت پشتیبانی + مشاهده پاسخ

**پنل ادمین 👑** (فقط آیدی مالک — دستور `/admin`)
- 💎 افزودن / ویرایش / حذف / فعال‌غیرفعال کردن پلن‌ها
- 🧾 تایید یا رد سفارش‌ها + تحویل خودکار کانفیگ
- 👥 مدیریت کاربران: مشاهده، جستجو، مسدودیت، افزایش روز اشتراک
- 🖥️ مدیریت سرورها + استخر کانفیگ آماده + قالب ساخت خودکار کانفیگ (`{UUID}` / `{EMAIL}`)
- 📊 آمار فروش و کاربران
- 📣 پیام همگانی (متن، عکس، ویدیو...)
- 💳 ثبت شماره کارت و صاحب کارت
- ⏳ یادآوری خودکار انقضا (۲۴ ساعت قبل) + غیرفعال‌سازی اشتراک تمام‌شده

**بکاپ و ریستور 💾**
- هر روز ساعت **۰۰:۰۰** (تهران) بکاپ خودکار + ارسال فایل به ادمین
- دستور `/backup` برای بکاپ فوری
- دستور `/restore` + ارسال فایل `.db` برای برگرداندن (با اعتبارسنجی + بکاپ اضطراری)

## 🚀 نصب سریع روی اوبونتو

```bash
# ۱) کلون
git clone https://github.com/USER/vpn-shop-bot.git /opt/vpnbot
cd /opt/vpnbot

# ۲) نصب (پیش‌نیازها + محیط مجازی + سرویس دائمی)
sudo bash install.sh
```

نصب‌کننده در حین کار ازت **توکن ربات** (از `@BotFather`) و **آیدی عددی** (از `@userinfobot`) را می‌پرسد و در `.env` ذخیره می‌کند. تمام!

> ⏰ ساعت سرور را روی تهران بگذار تا بکاپ دقیقاً ۰۰:۰۰ گرفته شود:
> `sudo timedatectl set-timezone Asia/Tehran`

## 🔧 نصب دستی (بدون اسکریپت)

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip sqlite3
cd /opt/vpnbot
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
./venv/bin/python config.py        # ویزارد ساخت .env
./venv/bin/python bot.py           # اجرای آزمایشی (Ctrl+C برای خروج)
```

**اجرای دائمی با systemd:**
```bash
sudo sed "s|/opt/vpnbot|$(pwd)|g" vpnbot.service > /etc/systemd/system/vpnbot.service
sudo systemctl daemon-reload
sudo systemctl enable --now vpnbot
```

**مدیریت سرویس:**
| دستور | کار |
|---|---|
| `sudo systemctl status vpnbot` | وضعیت |
| `sudo systemctl restart vpnbot` | ریستارت |
| `sudo systemctl stop vpnbot` | توقف |
| `sudo journalctl -u vpnbot -f` | لاگ زنده |

**اجرای موقت با screen (جایگزین systemd):**
```bash
screen -S vpnbot ./venv/bin/python bot.py
# جدا شدن: Ctrl+A سپس D | وصل شدن: screen -r vpnbot
```

## 📁 ساختار پروژه

```
vpnbot/
├── bot.py              # نقطه ورود: راه‌اندازی، زمان‌بند، polling
├── config.py           # خواندن .env + ویزارد اجرای اول
├── database.py         # لایه SQLite (کاربران، پلن‌ها، سفارش‌ها، ...)
├── keyboards.py        # همه کیبوردهای اینلاین
├── utils.py            # تاریخ، قیمت، ساخت کانفیگ
├── backup.py           # بکاپ روزانه، ریستور، یادآوری انقضا
├── handlers/
│   ├── user.py         # پنل کاربری
│   └── admin.py        # پنل ادمین
├── requirements.txt
├── .env.example        # نمونه تنظیمات
├── vpnbot.service      # سرویس systemd
├── install.sh          # نصب خودکار اوبونتو
├── data/               # دیتابیس + لاگ (خودکار ساخته می‌شود)
└── backups/            # بکاپ‌های روزانه (خودکار)
```

## ⚙️ متغیرهای `.env`

| متغیر | لازم | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات از BotFather |
| `ADMIN_ID` | ✅ | آیدی عددی مالک (مدیر) |
| `DB_PATH` | ❌ | پیش‌فرض `data/vpnbot.db` |
| `BACKUP_DIR` | ❌ | پیش‌فرض `backups` |

## 🖥️ کانفیگ‌ها چطور تحویل داده می‌شوند؟

دو حالت (قابل ترکیب):
1. **استخر آماده:** از پنل ادمین → سرورها → «افزودن کانفیگ آماده»؛ با هر تایید سفارش، قدیمی‌ترین کانفیگ آزاد تحویل و علامت‌گذاری می‌شود.
2. **قالب خودکار:** موقع ساخت سرور یک قالب بده که `{UUID}` و `{EMAIL}` داشته باشد؛ اگر استخر خالی بود، کانفیگ از روی قالب ساخته می‌شود.

> اگر پنل مدیریتی مثل 3x-ui داری، می‌توانی به‌جای این دو، در تابع تایید سفارش (`cb_order_ok` در `handlers/admin.py`) به API پنلت وصل شوی و کانفیگ واقعی بسازی — نقطه اتصال مشخص است.

## 🆘 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `TelegramUnauthorizedError` | توکن اشتباه است؛ `.env` را اصلاح و سرویس را ریستارت کن |
| پنل ادمین باز نمی‌شود | `ADMIN_ID` باید آیدی عددی خودت باشد، نه یوزرنیم |
| بکاپ سر ساعت نمی‌آید | تایم‌زون سرور: `sudo timedatectl set-timezone Asia/Tehran` |
| `address in use` / تداخل | فقط یک نمونه ربات روشن باشد: `systemctl stop` قبلی‌ها |
| دکمه‌ها کار نمی‌کنند | لاگ را ببین: `journalctl -u vpnbot -n 50` |

## 🔒 امنیت

- توکن فقط در `.env` روی سرور است و در گیت کامیت نمی‌شود (`.gitignore`).
- پنل ادمین فقط با آیدی عددی مالک باز می‌شود.
- فایل بکاپ فقط برای آیدی ادمین ارسال می‌شود.
- قبل از هر ریستور، فایل اعتبارسنجی + از وضعیت فعلی بکاپ اضطراری گرفته می‌شود.
