# ربات فروش فیلترشکن 🤖 (نسخه ۲)

ربات مستقل فروش اشتراک VPN با **aiogram 3** و **SQLite** — بدون وابستگی به هیچ پنل فروش دیگری.
دیتابیس، فایل‌ها و همه‌چیز فقط روی سرور خودت ذخیره می‌شود.

## ✨ امکانات

**کاربر:**
- 🛒 خرید پلن با کارت‌به‌کارت + ارسال رسید
- 🎁 اکانت تست رایگان (یک‌بارمصرف)
- 🎟️ کد تخفیف درصدی (با سقف استفاده)
- 👥 دعوت دوستان + هدیه روز اشتراک (حتی اگر اشتراک فعال نداشته باشی، محفوظ می‌ماند)
- 📢 جوین اجباری کانال (قابل تنظیم)
- 🔗 لینک اشتراک (سابسکریپشن) + 📷 QR کد
- 📦 مشاهده اشتراک‌ها، دریافت کانفیگ، تمدید خودکار با خرید دوباره
- 🎫 تیکت پشتیبانی
- 💰 کیف پول: شارژ موجودی، خرید فوری بدون تایید ادمین، تاریخچه تراکنش‌ها
- ✨ ایموجی پریمیوم متحرک در متن‌ها و آیکون دکمه‌ها

**ادمین (`/admin`):**
- 👑 چند مدیر (مالک + ادمین کمکی)
- 🛡️ اتصال به **پنل PasarGuard**: ساخت خودکار یوزر + تمدید خودکار + لینک سابسکرایبشن
- ✏️ ویرایش همه متن‌ها و دکمه‌ها از داخل ربات (با پشتیبانی `{e:name}`)
- 🔗 دکمه‌های شیشه‌ای (لینک‌دار) در منوی اصلی
- ✨ ثبت ایموجی پریمیوم با فوروارد
- 🎟️ ساخت کد تخفیف
- 💰 تایید شارژهای کیف پول + تغییر موجودی کاربر
- ⚙️ تنظیمات تست / دعوت / جوین اجباری
- 💎 پلن‌ها، 🖥️ سرورها + استخر کانفیگ آماده، 🧾 سفارش‌ها، 🎫 تیکت‌ها، 📣 پیام همگانی
- 💾 بکاپ خودکار روزانه + ریستور

## 🚀 نصب روی سرور (اوبونتو/دبیان)

```bash
cd /opt/shop
git checkout arena/01a0d918-munu
cd vpnbot
sudo bash install.sh
```

نصب‌کننده: پیش‌نیازها → محیط مجازی → وابستگی‌ها → ویزارد توکن/ادمین → سرویس systemd.
اگر قبلاً نصب کرده‌ای، اجرای دوباره همین اسکریپت = **ارتقا** (فایل `.env` و دیتابیس دست نمی‌خورند).

دستورات مفید:

```bash
sudo systemctl status vpnbot      # وضعیت
sudo systemctl restart vpnbot     # ریستارت بعد از تغییر کد
sudo journalctl -u vpnbot -f      # لاگ زنده
```

## 🛡️ اتصال پنل پاسارگارد

۱. در پنل پاسارگارد یک **API Key** بساز (شروعش با `pg_key_` است) — یا یوزر/پسورد ادمین پنل را آماده کن.
۲. در ربات: `/admin` ← 🛡️ پنل‌های پاسارگارد ← ➕ افزودن پنل ← مراحل را برو.
۳. «🔌 تست اتصال» بزن تا مطمئن شوی وصل است.
۴. در 💎 پلن‌ها ← انتخاب پلن ← 🛡️ پنل پاسارگارد ← پنل را وصل کن.

از این به بعد با تایید هر سفارش، یوزر **خودکار** در پنل ساخته می‌شود و لینک سابسکرایبشن به خریدار داده می‌شود؛ تمدید هم خودکار در پنل اعمال می‌شود.
پلن‌های بدون پنل مثل قبل دستی تحویل داده می‌شوند (استخر کانفیگ / قالب سرور).

> نام کاربری ساخته‌شده در پنل از آیدی تلگرام + شماره سفارش ساخته می‌شود (مثلا `u12345678o12`).

## ✨ ایموجی پریمیوم

۱. `/admin` ← ✨ ایموجی پریمیوم ← ➕ افزودن.
۲. یک پیام که ایموجی پریمیوم (متحرک) دارد بفرست یا فوروارد کن.
۳. یک نام انگلیسی بده (مثلا `fire`).
۴. حالا در هر متنی بنویس `{e:fire}` — در پیام به‌صورت ایموجی متحرک، و در دکمه به‌صورت آیکون نمایش داده می‌شود.

## ✏️ ویرایش متن‌ها و دکمه‌ها

`/admin` ← ✏️ متن‌ها و دکمه‌ها ← دسته دکمه‌ها/پیام‌ها ← انتخاب متن ← ارسال متن جدید.
placeholderها (مثل `{name}`) و توکن‌های `{e:name}` را حفظ کن.

## 🎁 تست، دعوت، جوین اجباری

`/admin` ← ⚙️ تنظیمات:
- تست رایگان: روشن/خاموش، مدت (روز)، حجم (گیگ)
- دعوت: روشن/خاموش، هدیه دعوت‌کننده (روز)
- جوین اجباری: روشن/خاموش، آیدی کانال (`@username` یا عددی)، لینک عضویت

> ⚠️ برای جوین اجباری، ربات باید **ادمین کانال** باشد تا عضویت را چک کند.

## 📁 ساختار

```
vpnbot/
├── bot.py            # نقطه ورود + زمان‌بند بکاپ/انقضا
├── config.py         # تنظیمات و ویزارد اجرای اول
├── database.py       # لایه SQLite (مهاجرت خودکار نسخه‌ها)
├── texts.py          # متن‌های قابل ویرایش
├── premium.py        # ایموجی پریمیوم + تبدیل HTML به entities
├── keyboards.py      # کیبوردها
├── utils.py          # ابزارها (قالب‌بندی، ارسال px، ...)
├── backup.py         # بکاپ/ریستور/یادآوری انقضا
├── panels/           # کلاینت پنل‌ها (PasarGuard)
├── handlers/         # هندلرهای کاربر و ادمین
├── requirements.txt
├── install.sh
└── vpnbot.service
```
